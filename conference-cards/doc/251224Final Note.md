# UX3 三刀流交流研討會 - 互動名片系統技術描述報告

## 一、簡單描述

本專案為「UX3 三刀流交流研討會」量身打造的互動名片系統，旨在透過數位化技術提升研討會現場的社交互動體驗。系統核心結合了現代化的網頁開發框架與即時雲端資料庫，提供參與者從下載設計模板、個人化名片製作上傳，到現場動態瀏覽與隨機配對抽卡的全方位服務。使用者介面採用直觀、充滿科技感的 3D 翻轉卡片效果與響應式佈局，確保在各類行動裝置與桌機上均能擁有流暢且具層次感的互動體驗。

## 二、功能描述

1.  **個人名片管理與上傳**：
    - **描述**：提供專業 Figma 模板下載，並支援參與者自行上傳名片正反面圖片，具備即時預覽功能。
    - **技術說明**：前端使用 `React Hook Form` 與 `Zod` 進行嚴謹的表單驗證，圖片處理接軌 `Cloudinary` 服務進行雲端存儲與動態比例剪裁，確保上傳效率與顯示品質。
2.  **3D 互動名片牆**：
    - **描述**：動態展示所有參與者的名片，使用者可以透過滑鼠懸停或觸控使卡片翻轉，查看更詳細的個人資訊。
    - **技術說明**：利用 `Framer Motion` 執行複雜的 3D 旋轉動畫與物理回饋效果，並搭配 `Next.js` 的圖片優化（`next/image`）提升首刷速與載入性能。
3.  **現場抽卡配對系統**：
    - **描述**：專為現場活動設計的抽卡模組，能夠從參與者名單中隨機抽取對象進行配對。
    - **技術說明**：基於 `Firebase Firestore` 進行資料讀取與更新，確保資料的一致性，並透過動畫呈現抽卡的過程與結果。
4.  **管理者控制後台**：
    - **描述**：供管理員審核上傳內容、監控系統統計數據與控制現場抽卡重置。
    - **技術說明**：建構於 `Next.js` 路由系統下的管理頁面，結合 `Firebase Auth`（支援 Google 登入）確保只有獲授權的人員可以操作核心管理功能。

## 三、完整技術描述

### 前端技術

- **Next.js 14 (App Router)**：作為專案核心框架，利用其伺服器組件（Server Components）提升首屏載入速度，並透過路由處理程序（Route Handlers）建構內部的 API。
- **TypeScript**：採用強型別開發，提高程式碼的健全性與可維護性。
- **Tailwind CSS**：利用 Utility-first 的特性快速建構響應式且具一致性的視覺語法，並整合 `shadcn/ui` (Radix UI) 提供高品質的可訪問性組件。
- **Framer Motion**：專門處理 UI 的流暢過渡與 3D 空間轉換效果，是本專案視覺亮點的核心推手。
- **Lucide React**：提供一套簡潔一致的向量圖標庫。

### 後端技術與資料處理

- **Firebase Firestore (NoSQL)**：作為主要的即時資料庫，儲存用戶資料與名片資訊，具備良好的擴展性與低延遲讀取。
- **Firebase Authentication**：整合 Google OAuth 登入，提供安全、快速的身份驗證流程。
- **Cloudinary**：用於處理高效能的圖片存儲與分發（CDN），並自動生成不同尺寸的縮圖以優化行動端頻寬。

### 系統架構與開發模式

- **模組化組件系統**：將 UI 拆分為高度可複用的組件（原子設計模式概念），並透過 `lib` 資料夾對 Firebase 與 Cloudinary 的 SDK 進行二次封裝，降低耦合度。
- **安全性架構**：透過 `middleware.ts` 進行路由訪問控制，並在 Firebase 設定 `firestore.rules` 確保資料權限安全。

## 四、未來可以改善的方向

1.  **離線支援與 PWA 化**：將系統轉換為漸進式網路應用（PWA），讓參與者在研討會現場網路較不穩定時仍能順暢瀏覽已載入的名片資訊。
2.  **進階社交特徵**：增加標籤（Tags）過濾與搜尋功能，讓參與者能依據「感興趣的領域」快速找到潛在的交流對象。
3.  **效能監控實作**：引入 Vercel Speed Insights 或其他 APM 工具，分析各類裝置上的 LCP (Largest Contentful Paint)，針對動畫負擔重的低階手機進行更有針對性的降級優化。
4.  **即時互動強化**：利用 Firestore 的 `onSnapshot` 監聽功能，實作更即時的通知系統（例如當有人對你的名片感興趣時發出小燈號提示）。
